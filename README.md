# A Very Normal Simulator
This is the home of my AP Computer Science A project. Scored 20/20. <br> <br>
This choose your own adventure game written in Java centers around being a very ordinary fishkeeper. It is ``*just*`` a normal simulator. There are no secrets to find. Made in 2024

Inspired by my experience with coding previous text adventures.

There were a few software design choices:
- Uses OOP
- User's ease of use (For instance, having a select number menu rather than typing out the entire action request)
- Debugging controls, for easier debugging
- Function overloading, so that an operation and variations can be called using the same function.
